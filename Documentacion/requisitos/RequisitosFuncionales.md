## Requisitos Funcionales (RF)

Este documento clasifica los requisitos funcionales

| ID | Categoría | Requisito Funcional | Prioridad |
| :--- | :--- | :--- | :--- |
| **RF-001** | Acceso | Registro de nuevos usuarios. | Alta |
| **RF-002** | Acceso | Login de usuarios registrados. | Alta |
| **RF-010** | Búsqueda | Buscador de términos musicales. | Alta |
| **RF-011** | Búsqueda | Conexión con API de YouTube para resultados. | Alta |
| **RF-012** | Descarga | Descarga de archivos de audio al disco local. | Alta |
| **RF-020** | Playlist | Crear nuevas playlists. | Alta |
| **RF-021** | Playlist | Eliminar playlists existentes. | Alta |
| **RF-022** | Playlist | Añadir canciones descargadas a playlists. | Alta |
| **RF-030** | Reproducción | Controles básicos (Play, Pause, Next, Prev). | Alta |
| **RF-032** | Reproducción | Modo Aleatorio (Shuffle). | Media |
| **RF-040** | Interfaz | Barra de control de volumen. | Alta |
| **RF-041** | Interfaz | Barra de progreso interactiva (*Seek*). | Alta |
