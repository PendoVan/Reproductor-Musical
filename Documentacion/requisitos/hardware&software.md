# 💻 Hardware y Software

Este documento detalla las especificaciones mínimas de hardware y software necesarias para la correcta instalación y ejecución del Reproductor de Música de Escritorio.

## Requisitos de Hardware

Para garantizar un rendimiento fluido de la aplicación JavaFX y la reproducción de audio, el equipo del usuario debe cumplir con lo siguiente:

| Componente | Requisito Mínimo | Recomendado |
| :--- | :--- | :--- |
| **Procesador (CPU)** | Intel Core i3 (5ta gen) / AMD Ryzen 3 o equivalente | Intel Core i5 / AMD Ryzen 5 |
| **Memoria RAM** | 4 GB | 8 GB o más |
| **Almacenamiento** | 500 MB libres para instalación | 5 GB+ libres (depende de la cantidad de música a descargar) |
| **Tarjeta de Sonido** | Integrada estándar compatible con DirectX/Drivers del SO | Dedicada o interfaz de audio externa |
| **Conexión a Internet** | 5 Mbps (para búsqueda y descarga) | 20 Mbps o superior (fibra óptica) |
| **Pantalla** | Resolución 1280x720 (HD) | Resolución 1920x1080 (Full HD) |

## Requisitos de Software

El entorno de operación debe contar con:

* **Sistema Operativo:** Microsoft Windows 10 (64-bits) versión 1903 o superior, o Windows 11.
* **Entorno de Ejecución Java (JRE):** Versión 17 o superior (si la aplicación no incluye el JRE empaquetado).
* **Controladores de Audio:** Drivers actualizados del fabricante de la tarjeta de sonido.
* **Permisos:** Privilegios de administrador para la instalación inicial y permisos de escritura en la carpeta de destino de las descargas.
