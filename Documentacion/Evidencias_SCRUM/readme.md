

# **00 Evidencias de Metodología SCRUM**

## 1. Introducción

El presente documento reúne los **artefactos, entregables y registros formales** correspondientes a la metodología **Scrum ligera** aplicada durante el desarrollo del proyecto **Reproductor Musical**.

Su propósito es evidenciar el proceso de planificación, ejecución, control y validación empleado por el equipo, detallando los entregables generados en cada una de las etapas.

Estos archivos complementan los documentos principales del proyecto y forman parte del conjunto integral de gestión del mismo.

## 5. Conclusión

Las evidencias presentadas demuestran el uso de una **metodología de trabajo estructurada**, basada en principios de **Scrum**, permitiendo llevar a cabo:

* La planificación por iteraciones.
* La asignación clara de tareas y responsabilidades.
* El seguimiento del avance del proyecto.
* La validación progresiva del producto.
* La mejora continua mediante retrospectivas.

Este conjunto de documentos respalda el desarrollo del **Reproductor Musical** como un proyecto académico ejecutado bajo un enfoque metodológico sólido, verificable y reproducible.
