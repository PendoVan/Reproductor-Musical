# E01 – Product Backlog

El Product Backlog es la lista priorizada de funcionalidades del sistema Reproductor Musical.  
Cada elemento incluye una descripción general, prioridad y estado de avance.

| ID     | Elemento del Backlog                 | Descripción                                                                 | Prioridad | Estado       |
|--------|--------------------------------------|-------------------------------------------------------------------------------|-----------|--------------|
| PB-01  | Reproducción de música local         | Permitir reproducir archivos MP3 y WAV desde el equipo local.               | Alta      | Completado   |
| PB-02  | Controles multimedia                 | Implementar play, pause, stop, siguiente, anterior y control de volumen.     | Alta      | Completado   |
| PB-03  | Sistema de playlists                 | Crear, editar, eliminar y reordenar listas de reproducción.                  | Alta      | Completado   |
| PB-04  | GUI con JavaFX                       | Diseñar una interfaz visual intuitiva y funcional.                           | Media     | Completado   |
| PB-05  | Búsqueda de canciones locales         | Implementar un buscador de archivos dentro de carpetas seleccionadas.       | Media     | Completado    |
| PB-06  | Integración con API externa           | Búsqueda y reproducción de música mediante una API en línea.                | Media     | Completado  |
| PB-07  | Ecualizador / mejoras visuales        | Añadir ajuste de graves/agudos y mejoras estéticas.                         | Baja      | Completado    |
