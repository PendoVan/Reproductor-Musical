# Introducción

Este documento describe el **plan de proyecto** para el desarrollo del prototipo de software **“Reproductor de Música (JavaFX)”**, una aplicación de escritorio desarrollada en **JavaFX** y diseñada con **Scene Builder**, cuyo objetivo es ofrecer al usuario una forma sencilla, moderna y eficiente de reproducir archivos de audio locales.

El propósito de este plan es proporcionar una guía clara sobre la **planificación, organización, recursos, riesgos y cronograma** necesarios para el desarrollo del sistema, desde la fase de análisis hasta la entrega final. Además, servirá como punto de referencia para futuras ampliaciones del proyecto, como la integración con una base de datos, inicio de sesión, gestión de playlists y búsqueda de canciones mediante API.

---

## Descripción general del proyecto

El **Reproductor de Música (JavaFX)** permite al usuario:
- Cargar archivos de audio locales (.mp3 o .wav).  
- Reproducir, pausar, detener, avanzar o retroceder entre canciones.  
- Visualizar una lista temporal de canciones cargadas.  
- Ajustar el volumen desde la interfaz.  

Las funcionalidades futuras incluyen:
- Sistema de login y registro de usuarios.  
- Creación y gestión de playlists.  
- Conexión a una API para buscar y reproducir música en línea.  

---

## Objetivos del proyecto

1. **Desarrollar un reproductor de música funcional** con una interfaz intuitiva y amigable.  
2. **Aplicar los principios del desarrollo modular y MVC** usando JavaFX.  
3. **Implementar controles multimedia básicos** (play, pause, stop, next, previous).  
4. **Documentar el proceso de planificación y desarrollo** del software para uso académico.  
5. **Proveer la base para futuras versiones conectadas a una base de datos y servicios online.**

---

## Alcance y limitaciones

**Alcance (versión local):**
- Ejecución independiente en entorno de escritorio.  
- Carga manual de archivos de música desde el sistema local.  
- Sin conexión a internet ni base de datos.

**Limitaciones:**
- No incluye almacenamiento persistente.  
- Soporta solo formatos .mp3 y .wav.  
- No posee integración con API externa (planificado para una versión posterior).
