# Planificación del Proyecto de Software  
## Reproductor de Música (JavaFX)

El **Reproductor de Música (JavaFX)** es una aplicación de escritorio desarrollada con **JavaFX** y **Scene Builder**, cuyo objetivo es ofrecer al usuario una interfaz intuitiva para reproducir canciones locales.  
Este repositorio contiene la **planificación completa del proyecto**, incluyendo los documentos que definen su estructura, roles, riesgos y desarrollo.

---

## Descripción General

Este plan de proyecto establece los **recursos disponibles**, **roles del equipo** y **fases de trabajo** necesarias para llevar a cabo el desarrollo del sistema.  
El objetivo es garantizar una planificación clara y organizada que sirva como base para el desarrollo del software y su documentación.

Los integrantes del equipo utilizaron herramientas de gestión como **GitHub Projects** y **diagramas de Gantt** para planificar las tareas y controlar los avances.
