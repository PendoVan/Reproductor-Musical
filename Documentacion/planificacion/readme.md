# Planificación del proyecto de software
El plan del proyecto establece los recursos disponibles para el proyecto para llevar a cabo el trabajo. Los EDs utilizarán la herramienta de su preferencia para elaborar su cronograma de trabajo. El plan de proyecto se consideran las siguientes secciones:

- [Introducción](introduccion.md)
- [Organización del proyecto](organizacion.md)
- [Desglose del trabajo](desglose.md)
- [Riesgos](riesgos.md)
