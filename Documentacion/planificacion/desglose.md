# Desglose del Trabajo (WBS)

Una **Estructura de Desglose de Trabajo (EDT)**, también conocida como **WBS (Work Breakdown Structure)**, es la descomposición jerárquica del proyecto en fases, actividades y tareas que permiten organizar y gestionar de forma eficiente el desarrollo del **Reproductor de Música (JavaFX)**.

---

## 1. Análisis
- Recopilar requisitos del sistema (funcionales y no funcionales)
- Documentar los casos de uso del reproductor
- Definir el alcance de la versión local y planificar futuras ampliaciones

## 2. Diseño
- Elaborar el modelo de datos (estructura de playlists y canciones)
- Diseñar la interfaz gráfica en **Scene Builder**
- Definir la arquitectura del sistema (modelo MVC con JavaFX)

## 3. Implementación
- **Backend:** Lógica de reproducción (MediaPlayer), controladores y gestión de listas
- **Frontend:** Interfaz visual con botones de control, listas de canciones y control de volumen
- Configuración de librerías JavaFX en Eclipse

## 4. Pruebas
- **Unitarias:** Validación de métodos (play, pause, stop, etc.)
- **Integración:** Verificación del flujo completo entre GUI y lógica de negocio
- Solución de errores frecuentes (p. ej., librerías faltantes, formatos no soportados)

## 5. Entrega
- Elaboración de la **documentación final** (manual de usuario y planificación)
- **Presentación del proyecto** y demostración funcional en GitHub
