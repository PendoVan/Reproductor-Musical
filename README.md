# 🎧 Reproductor de Música 

## 🎶 Descripción del Proyecto

Nuestro proyecto es un reproductor de música de escritorio desarrollado en **JavaFX** que combina la funcionalidad de un reproductor local con la ventaja de poder descargar canciones de manera sencilla.

El objetivo principal es permitir a los usuarios gestionar sus propias playlists personalizadas, utilizando la **API de YouTube** como motor de búsqueda para encontrar y descargar contenido musical.
